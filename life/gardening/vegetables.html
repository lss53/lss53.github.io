三、通用栽培操作

1. 浸种催芽

春季育苗：

卫生纸包种扎紧 → 按表浸泡（以包装说明为准）
→ 拧至不滴水，装塑料盒 → 恒温箱25–32℃催芽
→ 每24h检查一次 → 60%露白（顶端出小芽）即播种
  • 无恒温箱：放在光猫、路由器等持续发热设备上，每天检查防烫。
    秋季甘蓝类：包好浸透 → 常温24h → 拧干直接播苗床。

2. 育苗

春季（冷凉）：

  • 育苗土：草木灰:细泥土 = 1:10，要求细腻疏松、无大颗粒或结块
  • 50孔盘装满土，用另一盘底部按压，形成整齐播种穴，每穴1粒
  • 盘面盖白地膜（保温保湿），放入小拱棚
  • 拱棚材料：竹片长2m；棚膜4丝、宽2m；白地膜1.4丝、宽1–1.5m
  • 无盘替代：菜地直接搭小拱棚 → 浇透地 → 按5×5cm株行距平放露白种子 → 盖育苗土 → 喷雾湿润 → 盖白地膜（出苗后揭除）→ 盖小拱棚膜
    秋季（高温）：
  • 苗床开沟深3–5cm、沟距20cm，沟内浇透水
  • 每沟一个品种，种子间距5cm摆沟两侧
  • 盖细土，喷头贴地面调细雾浇湿
  • 搭小拱棚盖遮阳网16–18针（可降温4–6℃）
  • 每天浇一次水；早7–9点掀棚见光防徒长

3. 整地与覆膜（播栽前完成；早播地块3月20日前就绪，一般地块3月20日后深翻）

深翻 → 晒地2天（利用阳光杀菌）
→ 每㎡撒有机菌肥5g + 高钾肥5g（共10g≈半把）
→ 敲碎大泥块、整平 → 土壤稍干后开沟起垄
→ 垄面宽90–100cm，中间高两边低 → 盖地膜
  • 有机菌肥 = 有机肥（发酵好的鸡粪、羊粪、秸杆、豆粕等）+ 有益菌（枯草芽孢杆菌、木霉菌、固氮菌等）；作用：改良土壤、提高作物口感
  • 高钾肥：促进作物生长

地膜选择：

地膜类型厚度宽度特点
白地膜1.4–2丝1.5m保温效果好，早春低温用（5月底必须撤）
银地膜1.4–2丝1.5m防草 + 保温，杂草多地用

4. 炼苗与移栽（六步）

总原则：日期只是参考，真叶数 + 夜温门槛才是准绳。

① 提前7天炼苗：第1–2天棚一头通风；第3–7天两头通风
   ▸ 炼苗期喷雾（可选）：
     促根——高钾肥1g兑1斤水喷1次；
     防病——幼苗生病时，克露1g兑1斤水喷1次
② 查苗龄卡：真叶数达标 + 夜温门槛达标
③ 地膜打孔（略大于穴盘孔），带完整土坨取出放入
④ 覆土压实
⑤ 立刻浇透定根水，检查孔口封严
⑥ 3–5天缓苗期避强光（晴天高温遮阴或傍晚叶面喷水），7–10天后查苗补苗

5. 撒播四步（叶菜）

种子混半碗干细土（1g种子兑1斤细土）→ 均匀撒土面
→ 盖遮阳网，用细雾喷头一次性浇透
→ 出苗前每3天一水，保持湿润 → 出苗立即揭网 → 长挤了拔着吃

6. 搭人字架（植株高20cm时）

操作：取2m竹竿两根，分别插在植株外侧，向中间交叉；交叉点上方横放一根竹竿固定，用扎带绑牢。

搭架不搭架
黄瓜、丝瓜、苦瓜、瓠瓜、豇豆、四季豆、荷兰豆西瓜/南瓜/冬瓜（爬地）；西葫芦（矮生）；一切叶菜

四、田间管理

浇水总则

见干见湿、宁干勿涝、傍晚浇、雨后排涝。

保花保果（防落素，又名番茄灵）

温度1%原液用量兑水浓度
常规（≤28℃）5ml4斤（2000ml）25 mg/L
高温（>28℃）5ml6.7斤（3330ml）15 mg/L

新手最稳做法：买成品按瓶签配。
浓度计算：1%原液5ml含有效成分 5×1% = 0.05g = 50mg。常规：50mg÷2L = 25mg/L；高温：50mg÷3.33L ≈ 15mg/L（气温高时激素活性增强，需稀释降低浓度）。

  • 时间：开花–5月中旬，上午9–10时/下午3–4时，确保3小时无雨
  • 番茄：每穗2–3朵开放后，向花穗背面（花柄花萼处）喷2下，间隔5–7天共2次
  • 西瓜/南瓜/西葫芦：向每朵开放雌花花蕊连喷2下

五、番茄·辣椒专项

最复杂作物，其余可不管。
番茄与辣椒均需整枝，方法相同。

  1. 首次整枝（株高20cm时）：
    • 去掉10cm以下侧蔓和叶子
    • 顶端出现“Y”字型分叉时，保留1主蔓+1侧蔓形成双蔓
    • 选晴天（确保半天无雨）操作；此后每3–5天打一次杈（侧蔓=主蔓上长出的侧生分枝）
  2. 追肥（结2串果后）：每株高钾肥10g+叶面（微量元素+钾钙宝），每7天1次共4次（整个5月，下午3–4点）
  3. 疏果：果实长至蚕豆大小时（宜早勿晚），每串留4个大小均匀、果脐不发黑的果；疏后喷一次微量元素+钾钙宝；剪除植株30cm以下老叶（约3片）
  4. 防鸟（6月）：防鸟网，网孔约硬币大小，线径24股，宽2m
  5. 打顶（6月底）：大番茄留5串果、小番茄留6串果后摘除顶端生长点
